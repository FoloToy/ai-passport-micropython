# Documentation index

This documentation is written for AI agents and users developing with AI. Read it in this order:

1. `ai-workflow.md` — select a path and follow the delivery flow.
2. `requirements-template.md` — simple, conversational requirement prompts.
3. `quick-start.md` — default user-script development.
4. `script-development.md` — board APIs and examples.
5. `device-testing.md` — upload, run, and acceptance.
6. `environment-setup.md` — Linux, macOS, Windows, WSL2, and CI setup.
7. `firmware-development.md` — custom firmware only.
8. `troubleshooting.md` — symptom-based diagnosis.

Every new English document has a matching Simplified Chinese `*.zh_CN.md` file.
