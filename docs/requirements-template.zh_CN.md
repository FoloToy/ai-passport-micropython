# 白话需求记录

不要让用户一次填写长表格。AI 应该逐个询问下面的问题，并把答案记下来：

1. 你希望它帮你做什么？
2. 开机先显示什么？
3. 上下键和确认键分别做什么，是否区分长按？
4. 想显示什么字、图片和颜色，需要中文吗？
5. 需要播放声音、录音，还是两者都要？
6. 需要 Wi-Fi 或蓝牙做什么？
7. 要不要显示电量，多久不用后休眠？
8. 看到什么现象就算完成？

用户不知道时，AI 可以先给一个简单默认值，再让用户确认。例如：

```text
我要做一个桌面提醒器：开机显示时间，上下键切换提醒，确认键查看详情，需要中文和提示音，暂时不用网络，5 分钟无操作后休眠。能显示、能切换、能响铃、能唤醒就算完成。
```

如果用户只说“做一个应用”，AI 应继续用上面的问题引导，而不是复制测试菜单。
