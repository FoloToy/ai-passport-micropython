# 文档导航

本目录面向 AI 智能体和使用 AI 开发的用户。推荐阅读顺序：

1. `ai-workflow.md`：选择开发方式和完整交付流程。
2. `requirements-template.md`：白话需求引导。
3. `quick-start.md`：默认脚本路径。
4. `script-development.md`：使用板卡基础 API。
5. `device-testing.md`：上传、运行和验收。
6. `environment-setup.md`：Linux、macOS、Windows、WSL2 和 CI 环境。
7. `firmware-development.md`：需要底层改动时阅读。
8. `troubleshooting.md`：遇到问题时排查。
