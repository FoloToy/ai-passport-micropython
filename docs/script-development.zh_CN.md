# 用户脚本开发：AI 执行手册

这份文档主要给 AI 智能体看。用户只需要用白话说想实现什么，AI 负责追问、选示例、写脚本、上传运行并反馈结果，不要让用户先理解硬件 API。

## AI 执行流程

1. 先读 `AGENTS.md`、`docs/ai-workflow.md` 和本文件。
2. 缺什么就一次问一个简短问题，不要把硬件参数表直接发给用户。
3. 先判断 `main.py` 是否能完成；只有缺少底层能力时才选择自定义固件。
4. 选择最接近的示例，只复用硬件初始化，重新设计产品 UI 和流程。
5. 先做一个能看见的最小功能，再逐个加入外设。
6. 做语法检查，用 `tools/upload_main.sh` 上传，重启后观察串口和屏幕。
7. 分开说明已验证、未验证和下一步测试；不能把编译成功说成实机验证。

用户只说“做一个应用”时，先问“开机后先显示什么？”，不要直接复制硬件测试菜单作为产品界面。

## 基础接口

```python
from machine import ADC, I2C, I2S, Pin, SPI, PWM
```

板卡冻结了 `st7789`、`lvgl_st7789`、`lv_utils`、`es8311` 薄封装。它们用于减少初始化代码，但不替代应用自己的状态机和 UI 设计。

## 屏幕和按键

ST7789 基础引脚：SCLK=8、MOSI=9、CS=1、DC=20、背光=21。GPIO0 是 ADC 电阻分压按键。应用应使用非阻塞轮询或定时器，区分按下、释放、短按和长按；耗时工作不能放在按键回调中。

LVGL 操作必须在同一个 LVGL 执行上下文中完成。中文显示前必须准备包含目标汉字的字体，默认 Montserrat 字体不保证包含中文。

## ES8311 音频

ES8311 使用 I²C `0x18`。I²S 必须提供 MCLK：GPIO6；BCLK GPIO5；WS GPIO3；数据输出 GPIO2，输入 GPIO4：

```python
from machine import I2S, Pin
i2s = I2S(0, sck=Pin(5), ws=Pin(3), sd=Pin(2), mck=Pin(6),
          mode=I2S.TX, bits=16, format=I2S.MONO,
          rate=16000, ibuf=4096)
```

录音和播放要考虑资源释放、缓冲区、立即打断和异常恢复。停止 I²S 后再让 ES8311 休眠。

## 电池、Wi-Fi、BLE、低功耗

CW2017 使用共享 I²C 地址 `0x63`。扫描应在页面显示后启动，并在异步完成后更新结果。BLE 结果显示名称、完整 MAC 和 RSSI；无名称时只显示 MAC 和 RSSI。低功耗前停止扫描、音频和异步任务，唤醒后重新初始化外设。
